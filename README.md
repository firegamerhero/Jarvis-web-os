# Jarvis-web-os
hi there this is web os inspired by jarvis 
its an open sourse ' web based futuristic operating system with glassmorphic ui , 3Dinterative graphics , multi-modal gesture/voise control and an integrated cloud AI backend

## what are the ways to use
here some ways it support
1.keyboard and mouse
2. touch screen
3 gesture control
5. voise control


## 🚀 Key Features

- **🌐 Glassmorphism Window Manager:** Drag, resize, minimize, maximize, and tile floating glass application windows dynamically.
- **🌀 3D Interactive ARC Reactor:** Three.js particle core background that pulses and reacts to user interactions and audio.
- **🖐️ Computer Vision Gesture Control:** Powered by MediaPipe Hands for spatial hand-tracking (pinch to drag windows, open palm to pause/open launcher).
- **🎙️ Voice Command System:** Web Speech API integration for natural language OS commands and real-time audio responses.
- **🤖 Cloud AI Brain (Gemini API + Render):** External Python REST backend hosted on Render running Google Gemini for intent parsing, code generation, and automated OS tasks.


## 🛠️ Built-In Applications

1. **💻 Mark-8 Terminal:** Custom CLI with built-in system tools (`calc`, `theme`, `weather`, `systeminfo`).
2. **📝 Stark Notes:** Markdown editor with live side-by-side preview and LocalStorage auto-save.
3. **⏱️ Arc Focus Timer:** Interactive Pomodoro timer synced to 3D ARC reactor pulse animations.
4. **🧮 Dev Metrics Inspector:** Real-time FPS, memory usage, and system resolution analytics.
5. **🎵 Audio Matrix Visualizer:** Web Audio API synth with real-time frequency visualizers


## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Variables, Flexbox/Grid, Glassmorphic Backdrop Filters), JavaScript (ES6+ OOP)
- **3D & Vision:** Three.js, MediaPipe Hands JS, Web Speech API
- **Backend:** Python, FastAPI / Flask, Google Gemini API, Render (Cloud Hosting)
